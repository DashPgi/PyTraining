# ربات استیکر تاریخ روزانه

## چی درست شد؟

1. **فونت** - دیگه به `arial.ttf` گیر نمی‌کنه (که اصلاً روی هیچ سروری وجود نداره).
   حالا مسیر فونت رو با متغیر محیطی `FONT_PATH` خودت میدی. فقط فایل فونتت
   (مثلاً یه فونت فارسی مثل Vazirmatn) رو کنار پروژه بذار و اسمش رو به
   `FONT_PATH` بده.

2. **استیکر مربعی واقعی** - قبلاً کد با `send_photo` یه عکس معمولی می‌فرستاد،
   نه استیکر واقعی. تلگرام برای استیکر واقعی فایل **WEBP مربعی** (حداکثر
   ۵۱۲×۵۱۲) و متد `send_sticker` رو میخواد. الان `sticker.png` خودکار از وسط
   crop و به مربع ۵۱۲×۵۱۲ ریسایز و به WEBP تبدیل میشه.

3. **باگ چندخطی بودن متن** - چون متن تاریخ دو خط داره (`\n`)، از
   `multiline_textbbox` / `multiline_text` استفاده شد تا وسط‌چین درست انجام
   بشه.

4. **باگ فایل باز نشسته** - `open(...)` بدون `with` می‌موند و بسته نمی‌شد؛
   الان با `with` هندل میشه.

## درباره‌ی سرورلس (Vercel)

نکته‌ی مهم: کد قبلی‌ت (polling + APScheduler + `while True`) اصلاً روی
سرورلس (Vercel, و مشابه‌هاش) کار نمی‌کنه، چون:

- سرورلس یعنی هر درخواست یه پروسه‌ی کوتاه‌عمر جدا داره؛ نمی‌تونی یه پروسه
  رو ۲۴ ساعته روشن نگه داری تا polling یا scheduler داخلی کار کنه.
- توابع پایتون روی Vercel معمولاً بعد از چند ثانیه/دقیقه timeout میشن.

برای همین معماری عوض شد به دو تابع سرورلس جدا:

- **`api/webhook.py`** - وقتی کسی توی تلگرام `/date` یا `/id` بفرسته،
  تلگرام خودش یه درخواست HTTP به این آدرس میزنه (webhook)، دیگه نیازی به
  polling نیست.
- **`api/cron.py`** - هر روز توسط **Vercel Cron Jobs** (تعریف‌شده توی
  `vercel.json`) صدا زده میشه و استیکر روزانه رو میسازه و میفرسته.

### مراحل دیپلوی

1. `sticker.png` و فایل فونتت (مثلاً `font.ttf`) رو توی ریشه‌ی پروژه بذار.
2. پروژه رو به یه ریپازیتوری گیت‌هاب پوش کن.
3. توی [vercel.com](https://vercel.com) پروژه رو import کن.
4. توی تنظیمات پروژه (Environment Variables) این‌ها رو بذار:
   - `BOT_TOKEN`
   - `CHAT_ID`
   - `FONT_PATH` (مثلاً `font.ttf`)
   - `TELEGRAM_WEBHOOK_SECRET` (یه رشته‌ی رندوم دلخواه)
   - `CRON_SECRET` (یه رشته‌ی رندوم دیگه - Vercel خودش این رو به صورت
     خودکار به عنوان هدر `Authorization: Bearer ...` به درخواست کرون اضافه
     میکنه، پس نیازی نیست جای دیگه‌ای دستی صداش کنی)
5. دیپلوی کن و آدرس نهایی (چیزی مثل `https://your-project.vercel.app`) رو
   بردار.
6. یک بار، **روی سیستم خودت** (نه روی Vercel)، این رو اجرا کن تا وبهوک ثبت
   بشه:
   ```
   BOT_TOKEN=xxxx python set_webhook.py https://your-project.vercel.app YOUR_TELEGRAM_WEBHOOK_SECRET
   ```

### درباره‌ی زمان‌بندی کرون

- `vercel.json` الان روی `22 17 * * *` (به وقت UTC) تنظیم شده، که معادل
  ۲۰:۵۲ به وقت تهران (UTC+3:30) ـه.
- **مهم:** Vercel Cron روی پلن رایگان (Hobby) این محدودیت‌ها رو داره:
  - فقط **یک بار در روز** قابل اجراست.
  - زمان اجرا دقیق تضمین نیست؛ ممکنه هر لحظه توی همون **ساعت** مشخص‌شده
    اجرا بشه (نه دقیقاً همون دقیقه).
  - فقط UTC، بدون پشتیبانی از تایم‌زون.
- اگه زمان‌بندی دقیق برات مهمه، دو راه داری:
  1. آپگرید به پلن Pro (اجرا داخل همون دقیقه‌ی مشخص‌شده تضمین میشه).
  2. به‌جای کرون داخلی Vercel، یه سرویس کرون بیرونی رایگان مثل
     [cron-job.org](https://cron-job.org) بذاری که هر روز سر ساعت دقیق،
     یه GET request به `https://your-project.vercel.app/api/cron` بزنه
     (و هدر `Authorization: Bearer <CRON_SECRET>` رو دستی ست کنه).

## تست محلی

برای تست منطق (بدون خود Vercel) میتونی مستقیم توابع رو صدا بزنی:

```bash
pip install -r requirements.txt
BOT_TOKEN=xxx CHAT_ID=xxx FONT_PATH=font.ttf python -c "
from utils import get_date_info, create_sticker_image
print(create_sticker_image(get_date_info()))
"
```
