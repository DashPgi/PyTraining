## Six principles from CD (DAMA)

- Accurany 
    - Question -> How real is my data?
    - Formula -> (Accurate Data / All Data) * 100
- Completeness 
    - Question -> Is all my data complete? 
    - Formula -> (Required field non-empty values / All Records) * 100
- Validity
    - Question -> Is this data subject to rules and limitation?
- Freshness
    - Question -> Is this data is up to date?
- Consistancy
    - Question -> Is data the same across all systems and instances?
- Uniqueness
    - Question -> Is All of my data unique or not duplicated?
